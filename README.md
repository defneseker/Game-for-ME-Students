This repository holds the files that construct the game created for ME students.
This game features level-based progress which of each aims to facilitate the learning of a core concept in engineering via different kinds of gamification.
The game also has a coin management and shop system that deals with material updates, which is a further motivational element.

Note: The commits show only the version history of scripts (C# code files). In addition to the staged commit uploads, the game's code files that are taken directly from the last version of the game itself are uploaded as a zip file for any missing version updates/unnoticed mistakes for backup.

Technologies used:
- Unity Game Engine internal mechanics and systems
- C# OOP for script coding
- additional: Soundtrap for music, Piskel for sprites, FontStruct for custom fonts

Further development notes:
- The levels that have quiz-like dynamics have 4 questions for simplification purposes. This number can be incremented if wished.
- The actual mathematical numbers that are featured in the questions/objectives can be changed to reflect the physical reality portrayed in the question (esp. Level3).
- The main design/objective of each level is explained in the "instructions" for that level.
